# Werewolf Live Recorder

这是“狼人杀实战记录工具”的 GitHub Pages 静态站点版本。

## 发布方式

推荐方式：

1. 在 GitHub 新建仓库，例如 `werewolf-live-recorder`
2. 上传本文件夹里的 `index.html`、`.nojekyll`、`README.md`
3. 进入仓库 `Settings` -> `Pages`
4. `Source` 选择 `Deploy from a branch`
5. `Branch` 选择 `main` 和 `/root`
6. 保存后等待部署完成

最终链接通常是：

`https://你的GitHub用户名.github.io/werewolf-live-recorder/`

正式手机入口（Cloudflare Pages）：

`https://werewolf-live-recorder.pages.dev/`

Vercel 备用入口：

`https://werewolf-live-recorder-public.vercel.app/`

GitHub Pages 入口：

`https://aria777y.github.io/werewolf-live-recorder/`

GitHub Pages 备用入口（与“全国自驾游”页面同一个 GitHub Pages 站点）：

`https://aria777y.github.io/china_travel/werewolf/`

## 数据迁移

本工具的数据保存在当前浏览器本地。换到公网链接后，如果想带上旧记录：

1. 在旧页面点击“导出本局”
2. 在 GitHub Pages 页面点击“导入本局”
3. 选择导出的 JSON 文件
